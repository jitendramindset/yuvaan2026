## 🚀 3-Step Quickstart

### Step 1: Edit `.env`
```
botmantra-backend/.env

Add:
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USER=your-email@gmail.com
EMAIL_PASSWORD=your-app-password
EMAIL_FROM=noreply@yuvaan.app
```

### Step 2: Create Database Tables
```
Supabase Console → SQL Editor

Paste the SQL scripts from:
EMAIL_AND_GENEALOGY_IMPLEMENTATION.md
(Section: Database Tables Required)
```

### Step 3: Start Server
```bash
cd botmantra-backend
npm start
```

✅ **Done!** System is live on http://localhost:3000

## 📞 Support

**Email not sending?**
- Check .env has EMAIL_USER and EMAIL_PASSWORD
- For Gmail: Use [app-specific password](https://myaccount.google.com/apppasswords)
- Restart server after .env changes

**Genealogy not showing?**
- Ensure database tables are created
- Check browser console for errors
- Verify server is running on port 3000

**Database error?**
- Go to Supabase console
- Run SQL scripts in SQL Editor
- Verify tables exist
